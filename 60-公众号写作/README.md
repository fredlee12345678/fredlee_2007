# 60-公众号写作

这里用于沉淀公众号写作素材、选题、草稿、发布记录和复盘。

写作定位：
- 记录真实工作经历中的技术判断和成长
- 把 Android、基建、稳定性、工程效率、AI 提效经验结构化
- 将日常消耗转化为可公开表达的专业资产

## 推荐流程

1. `00-原始资料`：先记录真实事件和想法
2. `10-结构化事件`：抽取事实、动作、结果、影响
3. `20-能力资产`：提炼方法论
4. `60-公众号写作`：改写成可公开文章

## 文章分类

- Android 技术实践
- 工程效率与基建
- 稳定性与线上问题
- AI 辅助研发
- 职场复盘
- 个人成长与选择

## 坚持原则

- 不追求每篇都很大，先保持持续输出
- 每周至少维护 1 个选题
- 每两周至少发布或完成 1 篇可发布草稿
- 工作中的真实问题优先于空泛观点
